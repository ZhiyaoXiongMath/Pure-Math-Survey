The geometry pair retains complete statements for Rauch, Hessian and Laplacian comparison, Bishop–Gromov, Myers, Hadamard and Toponogov. The Lecture develops the Ricci-to-volume route and states the boundaries of its imported inputs. The time-compactness articles compare three original research sources and preserve an identical mathematical spine across the two Minimal views. The local examples develop completing the square, conditional Hölder compactness, and the Bochner-to-Lichnerowicz argument.

The replacement Hölder Lecture includes a direct weak-L2 calculation using finite orthonormal projections. Its predecessor is excluded from the current selection and retained privately as a superseded version. No old review was relabelled to approve the replacement.

## Reading and verification boundaries

`verification-manifest.json` is the authoritative current selection for the software verification workflow. Each project contains authored TeX, exact generated canonical statements, immutable selected materials, the required knowledge snapshots, and original author review records. The public `evidence/pages/` images are the actual reviewed pages. Project-level earlier inventories are retained verbatim as provenance; the root manifest and `article-inventory.json` define this selection.

All final pages were opened during author and non-author review. The separate non-author checks were performed within the same AI team. They are not external peer review, a real-student experiment, or a software release certification. `review-summary.json` reports the scoped conclusions, original report hashes and optional editorial notes.

The original eight expository release checks returned RELEASABLE. Those statuses belong to the original fixed build evidence. This source-only project export omits machine-specific build directories, histories and render manifests; its existing visual records are not fresh approval of an arbitrary rebuild. Rebuilds must retain current semantic bindings and receive the appropriate new page review. Installed-package and integrated software verification are separate later work.

The Paper is included only to demonstrate the draft boundary. Its source and PDF visibly identify the unverified status. The original runtime denied formal release and package creation. This developer corpus is not a formal research-paper package and makes no originality claim.

## Exact copies and private retention

`source-copy-inventory.json` binds every copied project file and PDF to its original bytes. `retained-private-inventory.json` records exclusions by relative path, hash and reason. No accepted record, generated fragment, immutable snapshot member or historical build report was edited to remove a path or refresh an acceptance hash.

Raw source PDFs, caches, private review transcripts, chat identifiers and local machine paths are excluded. Public source identities, versions, URLs, locators and provenance remain in the knowledge materials. Original machine-specific build/render reports, superseded outputs and failed attempts remain privately preserved. The original source PDFs remain privately retained where available; the online Shapiro source has a disclosed raw-hash limitation.

The public boundary check and read-only snapshot/structure checks are recorded in `export-checks.json`. They establish the scope of this copy operation, not new mathematical reasoning or a new PDF review.
