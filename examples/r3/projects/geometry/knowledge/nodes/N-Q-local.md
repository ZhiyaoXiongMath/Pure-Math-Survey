# How do curvature bounds control radial infinitesimal geometry?

## Explanation and evidence

Fix a smooth Riemannian metric, a base point or a unit speed geodesic, and a real comparison constant k. For every normal initial vector, which bounds on sectional curvature control its Jacobi field? Which bounds on Ricci curvature control only the trace of the distance Hessian? Determine exactly the time interval on which the comparison is meaningful. A choice of parallel frame changes matrices but not the comparison.

Answers are [[N-R-rauch]], [[N-R-hessian]] and [[N-R-laplacian]]. The bridges are [[N-M-riccati]] and [[N-M-trace]]. The cut/conjugate distinction is tested by [[N-E-cylinder]]. The question does not assert that bounds for traces imply bounds for every direction.
