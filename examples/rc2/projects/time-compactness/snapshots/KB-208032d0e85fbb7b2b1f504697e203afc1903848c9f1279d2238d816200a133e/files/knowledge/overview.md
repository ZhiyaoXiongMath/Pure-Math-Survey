# Which estimate belongs to which unknown?

The common target is strong compactness of trajectories on a fixed finite interval. The obstacle is a mismatch between the object with spatial control and the object with time control. Three routes answer different versions of that mismatch. A bounded set of spatial states alone cannot stop time oscillation, while time regularity in a weak space cannot by itself supply strong spatial compactness.

For X compactly embedded in B and B in Y, spatial information is a linear norm on f. Interval integrals remain in X and are compact in Y. Simon's time criterion gives weak-space compactness; ||z||B<=eta||z||X+C_eta||z||Y upgrades its Cauchy subsequences. The parameter eta is chosen before the subsequence index. The exact answer is N-simon and its decisive interface is N-linear-mechanism.

For a compact nonlinear K:E1->E2, coercivity may control u while the equation differentiates v=K(u). The identity K(int u)=int K(u) is unavailable. N-truncation instead removes G_M={||u||>M}, estimates its measure by C/M, and controls the output tail by Holder with r>1. Truncated outputs lie in one compact set, whose closed convex hull contains their averages. The tail is controlled in L1 solely to obtain compact interval integrals; the final strong topology comes from the separately assumed Lp translations in N-maitre. Input compactness is not recovered without additional hypotheses: N-image-only calculates constant squared images of a separated input family.

The third-source increment changes the map substantially. A cone M+ with a degree-one gauge need not be additive, so [v-w] may not exist. Barrett--Suli's two-point comparison, N-cone-ehrling, uses [v]+[w] instead. Its normalized contradiction stays inside the cone by scaling each point separately. The principal N-cone allows a derivative only in A1 and concludes strong compactness in A0, with the precise excluded endpoint (p,q)=(infinity,1).

The proof route in N-cone-mechanism first obtains a uniform A1 supremum bound from W11. Gauge truncation then gives a small bad set and an A1 tail of order 1/R, avoiding any artificial r>1 gauge hypothesis. Compact interval averages and Simon's criterion give an A1-Cauchy subsequence. The two-point inequality upgrades it to A0. This local reconstruction is written out because the original v2 proof passage after (2.8) has an unresolved index-dependence justification; that passage is not an input to the reconstruction. The source theorem is not declared false.

There is a useful overlap, but no blanket equivalence. N-homogeneous-transfer fixes an injective compact map homogeneous of degree alpha>=1 and constructs [v]=||K^{-1}v||^alpha. Strongly measurable inverse lifts and the same output/derivative space are explicit. Gauge control gives L1 input control; W11 gives all output Lr bounds; derivative estimates give the exact translations for Maitre. Arbitrary cones need not arrive with this parametrization, and Maitre also admits noninjective maps. The comparison identifies precisely the extra structure, norm matching and exponent conversion.

The decisive boundary is independent of spatial complexity. N-endpoint calculates nonnegative ramps with supremum and derivative-L1 norms one. Their finite-p error is (n(p+1))^{-1/p}, but they have no supremum-convergent subsequence. This prevents upgrading q=1 to the infinity conclusion. In contrast, r>1 in Maitre's selected tail argument is not a necessary boundary of the field: the original Chen--Liu 2012 statement located during discovery weakens that input.
