# Which spatial and temporal inputs force strong compactness?

For a fixed finite time interval and fixed Banach spaces, identify hypotheses ensuring that every sequence in a trajectory family has a strongly Lp-convergent subsequence. Track which unknown is estimated: u, K(u), or a cone-valued v. Compare arbitrary nonlinear maps with degree-one cone gauges only through explicit arguments. The endpoint p=infinity must be distinguished from all finite exponents. Scope excludes a strongest-known theorem claim and PDE solvability.
