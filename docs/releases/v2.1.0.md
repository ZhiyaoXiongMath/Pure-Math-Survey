## 简体中文

这是软件 2.1.0 的发行准备说明。正式发布与否以 [GitHub Releases](https://github.com/ZhiyaoXiongMath/Pure-Math-Survey/releases) 中非预发布的 `v2.1.0` 及完整安装附件为准；文档、绿色 CI 或 RELEASE_READY 都不表示已经发布。历史 `v2.1.0-r4-preview.1` 保留。

| 身份 | 当前值 |
|---|---|
| 软件 | 2.1.0 |
| 知识／快照 schema | 2.0.0 |
| 输出／审阅 schema | 2.2.0 |
| 写作政策 | four-modes-2026-10-15-r5 |

当前功能：维护有来源与成对快慢解释的统一 KB，经非作者审阅后冻结不可变快照；只生成请求的 Minimal、Thematic、Lecture 或 Paper 草稿，也可只建知识。四模式保留各自结构、准确完整主结果、具体证明承诺、编号而无描述标题的数学陈述及就近归属。来源访问、阅读范围、版本／定位、可重哈希字节和再分发许可分别记录；知识 READY 与 Paper 正式研究资格分别把关。工程流程包含安全路径、最终候选暂存／回滚、资源／包哈希、隔离安装和 Linux／Windows 验证。

安装：按 [README 的核验步骤](../../README.md#安装与核验)取得并校验 `pure-math-survey-2.1.0.zip` 与同名 `.zip.sha256`，使用整个解压文件夹。自动 Source code ZIP 不是安装包。脚本使用 Python 3.10+ 标准库；PDF 另需 pdfLaTeX、BibTeX、所需 TeX 包和 Poppler。完整自动工作流还依赖宿主实际可用的工作聊天工具与 `gpt-6-astra / ultra`。正式附件不存在时，可按 README 构建本地候选检查包。

工程验证：合并基线 `d76e18f7d863f2b755f4e4aa9089e88b03d9c99f` 的[实际 main CI](https://github.com/ZhiyaoXiongMath/Pure-Math-Survey/actions/runs/38846120380)已通过 Linux Python 3.10／3.12 与 Windows Python 3.12 的回归、隔离安装及中性 TeX smoke。安装验证共 344 项；Linux 实际执行 341 项，另 3 项为声明的 Windows 专用，Windows 执行全部 344 项。发行准备 PR 另须取得当前 HEAD 同三项 CI 和之后的独立非作者审查；最终发行检查必须绑定合并后的最终 main。

数学验收：已完成的真实比较定理任务采用 13 节点、12 个 canonical statements、6 个选定来源及 67 成员冻结快照。Minimal 11 页、Thematic 12 页、Lecture 15 页、Paper 草稿 12 页，合计 50 页，具有实际独立数学及逐页审阅。前三项按其许可完成可重建文章包；已知结果 Paper 保持 `DRAFT_UNVERIFIED`，原创贡献／证明资格及正式交付拒绝符合预期，没有正式 Paper 包。验收只在运行时代码、数学规则及证据哈希适用时复用；本次发行文档不重跑数学 E2E。

保留边界：四项流程／记账例外仍披露，协议不是无例外 PASS；原始来源的阅读范围及再分发限制不扩大。相同宿主的独立重建具有 50 页相同图像，但 PDF 二进制哈希不同；工程跨平台 CI 不认证跨平台数学重建。未实施真实学生学习研究、外部人工学术同行评审或原创性认证，也未取得正式原创研究证明资格；未承诺的全局理论仍在范围外。历史 E01–E05 的失败／暂停及各自报告保留，不改写为全部通过。私人原文、KB、正文、PDF 和验收日志不进入公开软件附件。

发行门槛：准备 PR 保持 OPEN，等待用户手动合并。合并并获继续授权后，核实最终 main 及 CI、数学验收绑定、最终安装包白名单／路径／CRC／成员与源文件哈希、无 pip／无系统 site-packages 的隔离运行及 TeX 检查，再检查 tag／Release 冲突。发布后还需回读实际 tag 指向、正式发布状态与仅两个安装附件，并重新下载核对哈希。本准备步骤不创建 tag 或 Release。

These notes prepare software 2.1.0. Publication is determined by a non-prerelease `v2.1.0` and its complete installation assets in [GitHub Releases](https://github.com/ZhiyaoXiongMath/Pure-Math-Survey/releases). Current capabilities: maintain one source-grounded KB with paired fast/slow explanations, then freeze an immutable snapshot after non-author review. Produce only requested Minimal, Thematic, Lecture or Paper drafts, or knowledge alone. Each mode retains its structure, accurate complete principals, concrete proof promises, numbered statements without descriptive titles and nearby attribution. Source access, reading scope, version/locators, rehashable bytes and redistribution permission are separate facts; knowledge READY and formal Paper research eligibility have separate gates. Engineering covers safe paths, final-candidate staging/rollback, resource/package hashes, isolated installation and Linux/Windows validation.

Installation: follow the [README verification steps](../../README.en.md#install-and-verify) for `pure-math-survey-2.1.0.zip` and its `.zip.sha256`, using the whole extracted folder. The automatic Source code ZIP is not the installation package. Scripts use Python 3.10+ standard library; PDFs additionally need pdfLaTeX, BibTeX, required TeX packages and Poppler. The complete automatic workflow also needs actual host work-chat tools and available `gpt-6-astra / ultra`. Before formal assets exist, the README provides a local candidate-package check.

Engineering evidence: [actual main CI](https://github.com/ZhiyaoXiongMath/Pure-Math-Survey/actions/runs/38846120380) for merged baseline `d76e18f7d863f2b755f4e4aa9089e88b03d9c99f` passed regression, isolated installation and neutral TeX smoke on Linux Python 3.10/3.12 and Windows Python 3.12. Installation verification covers 344 tests: Linux executes 341 with three declared Windows-only cases; Windows executes all 344. The preparation PR additionally requires the same three checks for its current HEAD, followed by independent non-author review. Final publication checks must bind to the final merged main.

Mathematical acceptance: the completed real comparison-theorem task uses 13 nodes, 12 canonical statements, six selected sources and a 67-member frozen snapshot. Minimal has 11 pages, Thematic 12, Lecture 15 and the Paper draft 12: 50 pages with actual independent mathematical and all-page review. The first three have rebuildable article packages under their delivery permissions. Known-result Paper remains `DRAFT_UNVERIFIED`; original-contribution/proof qualification and formal delivery are refused as expected, with no formal Paper package. Acceptance is reused only while runtime, mathematical rules and evidence hashes remain applicable; these release-documentation changes do not rerun mathematical E2E.

Retained limits: four process/bookkeeping exceptions remain disclosed; protocol compliance is not an unqualified PASS. Original-source reading and redistribution limits are unchanged. Same-host independent rebuilds have identical images for all 50 pages, with different PDF binary hashes; cross-platform engineering CI does not certify cross-platform mathematical reconstruction. No real student learning study, external human academic peer review or originality certification was performed, and formal original-research proof qualification is not established. Global theory outside the proof promises stays outside scope. Historical E01–E05 failures/pauses and their reports remain unchanged, rather than becoming an all-cases pass. Private originals, KB, manuscripts, PDFs and acceptance logs are excluded from public software assets.

Publication gates: keep the preparation PR OPEN for the user's manual merge. After merge and explicit continuation, reconfirm final main/CI, mathematical-acceptance binding, final package allowlist/paths/CRC/member and source hashes, no-pip/no-system-site-packages isolated execution and TeX checks, then tag/Release conflicts. After publication, reread the actual tag target, formal publication status and exactly two installation assets; download them again to verify hashes. This preparation step creates no tag or Release.
