# Formulate the knowledge scope first

Record in scope and question nodes: objects; intrinsic data; representative choices; unknowns and gauge; admissible variation domains; ordered quantifiers; exclusions. Justify material choices; do not freeze a background merely because a paper does. Avoid unmotivated maximal generality.

Distinguish `for a fixed ω, there exists α`, `there exists ω and α`, and `for every ω, there exists α_ω`. The last does not assert one common α or uniform estimates. An equivalence belongs in a reviewed relation/result with a source or actual argument.

Read the scope and definitions without the bibliography. Can the requested mathematical problem be recovered? Each output chooses question IDs without rewriting knowledge truth. Its opening must reproduce the selected scope before principal answers. `survey.py kb validate PROJECT` checks knowledge structure; `survey.py output validate PROJECT --output ID --stage release` checks the output release gate. This does not claim an automated quantifier interpretation.
