# Compact dHYM surface example

`dhym-surface-compact.tex` and its PDF illustrate a deliberately narrow smooth surface problem: the two-way reduction from the scalar dHYM equation to a complex Monge--Ampere equation, including the branch check and the shifted Kahler class. They are useful local exposition references for either edition, not a default scope for dHYM or Part V.

The source, PDF and accompanying `math-review.sty` are retained unchanged. The article's own date, conventions and references control the claims it presents; retention is not a fresh mathematical certification. Consult current primary sources before reusing a claim. No claim of independent review is attached to this example.

For an external build, copy the TeX and the neighboring style. To use the current shared style instead, copy `assets/templates/math-review.sty` explicitly. `scripts/build_checks.py` keeps these two dependency choices separate and leaves the original files unchanged.
