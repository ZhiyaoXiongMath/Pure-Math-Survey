# dHYM v6 exposition reference

`dhym-survey-polished-v6.tex` and its PDF are retained as supplied, together with `provenance.toml`. Their local mathematical exposition and readable layout can be consulted for either edition. They are not a whole-article template, a default topic inventory, or a new source certification.

The article's own literature date, conventions, references and scope remain attached to it. Check current controlling sources before using its claims; the filename denotes the article version, not the installed skill version. No new independent mathematical review is claimed by retention.

The TeX has its own preamble. `scripts/build_checks.py` builds an external copy with that preamble and another copy using the current shared style. These are dependency/build comparisons, not an approval of every statement or paragraph. The original TeX and PDF are not modified.
