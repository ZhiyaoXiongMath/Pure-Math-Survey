# Elementary exposition examples

The retained sources illustrate a quadratic minimum and a gradient iteration, with explicit assumptions, proofs, and label-free bodies for useful recalls. They are elementary writing and typesetting examples, not evidence about research-survey reliability.

`exposition-smoke.tex` uses `quadratic-body.tex` and `gradient-body.tex`. Copy these files and `assets/templates/math-review.sty` to an external directory before building, or use `scripts/build_checks.py`. The mathematical sources are retained unchanged from the supplied examples dated September 2026. This example makes no literature-frontier claim.
